# CONTACT（お問い合わせ・ご相談）

居心地が良く、住んでいて「楽しい」と感じられる家をつくるため、  
加藤淳設計事務所では、お客様とのコミュニケーションを大切にしています。  

建築する側のエゴではなく、家族にとっての本当の幸せを考えながら、家づくりをしています。  
家族の夢、建つ場所の環境、ライフスタイルの変化など、さまざまな条件を突き詰めていくと、不思議にプランもデザインも整っていきます。  

具体的に状況が固まっていない段階でも、ぜひお気軽にご相談ください。  
お客様の状況を整理していくことも得意とするところです。  
「こんなこと出来ますか？」「得意ですか？」といったご連絡も大歓迎です。  
前向きに、誠意をもってご対応させていただきます。  

ご相談については、お電話または下記のフォームよりお願いいたします。

## 見学会ご予約について

- 来場希望日・希望時間（10:00～17:00）を明記の上、ご送信ください。
- お子様連れのご来場も可能です。
- オーナー様のご厚意による見学会です。小さなお子様は手をつないでの見学をお願いいたします。
- ※ Newsの見学会情報にもご予約フォームがございます。どちらか片方からご連絡ください。
- ※ 予約状況により、時間変更をお願いすることがあります。

携帯メールのドメイン指定受信や、指定拒否をしている場合、当サイトからの予約完了通知などを受信できない場合があります。
